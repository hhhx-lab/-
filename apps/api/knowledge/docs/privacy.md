## 我们会收集什么 {#what-we-collect}

酷里会为了账号登录、订单沟通和交付保存你的邮箱、展示名、订单内容、附件信息、小酷对话摘要、访问日志和必要的安全审计记录。

## 为什么需要这些信息 {#why-we-use-it}

这些信息用于判断服务范围、推进订单、发送通知、回答与你订单或酷里业务相关的问题，以及保护账号安全。

## 谁可以看到 {#who-can-access}

普通用户只能看到自己的订单、公开消息、附件、报价、付款和交付物。管理员为了处理订单可以查看必要信息，内部备注、成本、利润和后台标签不会展示给普通用户。

## 小酷的边界 {#xiaoku-boundary}

小酷回答基于公开文档、当前页面和你自己的订单摘要。小酷不会读取其他用户订单，也不代表最终报价、周期或管理员承诺。

## 删除与处理请求 {#data-requests}

如果你需要处理、导出或删除自己的账号与订单数据，可以通过联系我们发起请求。涉及交付、对账和安全审计的信息可能需要按必要周期保留。
