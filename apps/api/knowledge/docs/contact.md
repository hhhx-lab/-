## 默认沟通方式 {#default-contact}

酷里默认通过站内订单跟进需求。沟通记录、报价、支付、交付和验收都会保留在订单页，方便后续对账和回看。

我们会用酷里小助手邮箱 team@kuly.com.cn 给用户发送关键状态提醒，例如订单已收到、管理员回复、报价、付款确认和交付更新。

## 安全提醒 {#safety-reminder}

不要在文档、订单消息、邮件或二维码渠道里直接发送密码、验证码、私钥、支付凭证和身份证等敏感信息。涉及账号类需求时，管理员会先确认安全方式。
