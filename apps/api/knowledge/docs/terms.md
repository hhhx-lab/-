## 咨询与报价 {#consulting-quote}

提交小纸条和基础咨询不等于酷里已经承诺接单。具体能否做、多少钱、多久完成，需要管理员基于材料和风险确认。

## 付款与验收 {#payment-acceptance}

小需求可以约定验收后付款，复杂需求可能需要先付定金。定金、尾款、验收节点和修改范围以订单中的管理员公开说明为准。

## 修改和售后 {#revision-aftercare}

交付后的修改以订单约定为准。默认不包含长期维护、账号托管、部署监控、第三方平台长期适配或无限次修改。

## 小酷的承诺边界 {#agent-boundary}

小酷可以解释服务、整理需求、提醒补材料和说明订单状态。小酷不代表最终报价，不承诺周期，不替管理员做最终承诺。

## 不接的需求 {#rejected-work}

违法违规、破解绕过、盗号、批量滥用平台、索要敏感凭证或风险不可控的需求，酷里会拒绝处理。
