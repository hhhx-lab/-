# 酷里 Kuly 四个服务详情页内容文案

本文档用于扩展 4 个服务详情页的核心文案：文档处理、AI 工具、小工具开发、部署配置。整体口径是：用户不需要先把需求说得很专业，只要把现状、材料、截图、目标效果发过来，酷里先判断能不能做，再拆范围、报方案、推进交付。

## 总体表达原则

- 不把服务写成固定套餐，而是写成“只要和这个方向相关，都可以先来问”。
- 强调酷里的能力是代办、协助、配置、排查、开发和交付，而不是只给建议。
- 对账号、订阅、网络和部署类服务，统一加上合规边界：在平台规则、法律法规和用户真实授权范围内协助处理。
- 对开发和部署类服务，明确可以从 demo 做到正式成品，但具体价格、周期、维护范围需要根据需求确认。

# 1. 文档处理

## 页面标题

万能文档处理

## 页面副标题

PPT、Word、论文、PDF、扫描件、图片转文字、格式规范、排版急救，只要是和文档有关的问题，都可以先丢给酷里试一试。

## 首屏介绍文案

文档问题最烦的地方，往往不是“不会写”，而是卡在一堆细碎但很耗时间的地方：格式乱了、页码不对、目录生成不了、图片糊了、PDF 改不了、PPT 不够像样、论文格式总被打回、扫描件想变成可编辑 Word、公式和表格一转换就崩。

酷里可以把这些文档杂活打包处理。你不用先判断它属于排版、转换、润色、重做还是格式规范，只要把文件和目标效果发来，我们先帮你拆问题，再判断适合人工处理、自动化处理，还是用 AI 加工具链一起处理。

## 我们可以处理什么

### PPT 制作与优化

- 根据主题、提纲、论文、报告或资料包制作 PPT。
- 美化现有 PPT，统一字体、颜色、版式、封面、目录、章节页和结尾页。
- 制作答辩 PPT、课程汇报 PPT、路演 PPT、项目展示 PPT、工作总结 PPT。
- 把 Word、PDF、Markdown、长文资料整理成适合演示的幻灯片。
- 优化图表、流程图、时间线、架构图、对比图和结论页。
- 按学校、企业、品牌或活动风格调整模板。

### Word 排版与格式调整

- 调整标题层级、正文样式、页边距、行距、缩进、页眉页脚、页码。
- 自动生成或修复目录、图目录、表目录。
- 统一字体、字号、编号、多级列表、表格样式和引用格式。
- 处理封面、摘要、目录、正文、参考文献、附录等完整结构。
- 修复复制粘贴导致的格式混乱、空白页、分页错乱、编号断裂。
- 把零散内容整理成正式报告、方案、说明书或提交稿。

### 论文与学术格式规范

- 按学校模板或期刊要求调整论文格式。
- 规范摘要、关键词、目录、图表编号、脚注、尾注、参考文献。
- 检查章节结构、标题层级、图表题注和附录编号。
- 协助处理本科论文、课程论文、开题报告、实验报告、调研报告、项目报告。
- 根据指定格式整理参考文献，如 GB/T 7714、APA、MLA、Chicago 等。
- 将老师或系统反馈的问题逐条改成可提交版本。

### 图片、扫描件、PDF 转 Word

- 图片转可编辑 Word。
- 扫描 PDF 转 Word，尽量保留原版式。
- 截图、照片、手写或打印材料识别成文字。
- PDF 内容提取、重排、合并、拆分、压缩和格式修复。
- 表格型 PDF 或图片转 Excel/Word 表格。
- 批量处理多页资料、试卷、合同、说明书、讲义和截图。

### 内容整理与文档重写

- 把一堆聊天记录、资料、网页、录音转写稿整理成结构化文档。
- 把口语化内容改成正式表达。
- 对简历、申请材料、项目介绍、产品说明进行润色。
- 对报告、方案、论文进行逻辑梳理、段落优化和语言统一。
- 中英文翻译、双语排版、术语统一和语气调整。
- 帮用户把“我大概想表达什么”整理成可交付文档。

### 表格、图表与数据文档

- Excel 表格清洗、格式调整、公式整理、数据透视和图表制作。
- 把数据结果整理成 Word 报告或 PPT 展示。
- 制作统计表、对比表、清单表、项目进度表、报价表。
- 把复杂表格改成更适合阅读、打印或汇报的版本。
- 修复表格跨页、边框错乱、列宽混乱、打印分页异常等问题。

### 文档工具链与格式转换

- Markdown 转 Word、PDF 或 PPT。
- Word、PDF、PPT、图片、Excel 之间互转。
- LaTeX、公式、参考文献、图表等学术材料整理。
- 文档批量命名、批量转换、批量拆分、批量合并。
- 建立可复用模板，比如论文模板、汇报模板、合同模板、日报周报模板。

## 适合哪些人

- 要交论文、报告、作业、答辩材料，但格式总是改不完的学生。
- 有 PPT、方案、汇报、总结材料要快速变好看的职场用户。
- 手里只有图片、扫描件或 PDF，但需要可编辑 Word 的用户。
- 有一堆资料想整理成正式文档的人。
- 不确定该用 Word、PPT、Excel、PDF 还是 Markdown，只想有人帮忙把结果做出来的人。

## 用户需要提供什么

- 原始文件、截图、扫描件、图片或资料包。
- 目标格式，例如 Word、PDF、PPT、Excel、Markdown。
- 参考模板、学校要求、老师反馈、企业规范或示例文件。
- 截止时间和最终用途。
- 希望保留的内容、必须修改的部分和不能改动的部分。

## 交付结果可以是什么

- 可编辑 Word 文档。
- 可演示 PPT。
- 可提交 PDF。
- 可继续编辑的 Excel 表格。
- 格式统一的论文、报告、方案、简历、说明书。
- OCR 后的文字稿、表格稿或结构化资料。
- 修改说明、处理清单和后续使用建议。

## 页面重点卖点

文档处理不是只会“改个格式”，而是从内容整理、格式规范、版式设计、格式转换、OCR 识别、图表处理到最终交付都可以接。你不用先懂文档工具，也不用自己在 Word、PPT、PDF、Excel 之间来回折腾。把材料发来，酷里先帮你判断最省事的处理路径。

# 2. AI 工具

## 页面标题

AI 工具与海外服务配置

## 页面副标题

ChatGPT、Gemini、Claude、Grok、Cursor、Claude Code、Codex、Antigravity、Telegram、Google 账号、中转站和 API 配置，账号、订阅、环境、工具链都可以找酷里协助。

## 首屏介绍文案

现在的 AI 工具很强，但真正用起来经常卡在第一步：账号注册不了、支付订阅失败、地区或网络环境不稳定、API Key 不知道怎么开、客户端装好了跑不起来、模型接入不知道填哪里、团队想用但不知道怎么配置。

酷里可以帮你把这些问题串起来处理：先解释工具是什么、适合做什么，再根据你的设备、用途和预算，协助完成账号、订阅、环境、客户端、API、中转站和开发工具配置。

所有账号和订阅类服务都以用户真实需求和合规使用为前提，在平台规则和用户授权范围内协助完成。

## 这些工具分别是什么

### ChatGPT

ChatGPT 是 OpenAI 的通用 AI 助手，适合写作、翻译、代码、学习、办公、数据分析、图片理解和多轮讨论。Plus、Pro、Team 等套餐可以提供更强模型、更高额度和更多高级功能。对于个人学习、创作、代码开发和工作提效，ChatGPT 是最常用的入口之一。

酷里可以协助：

- ChatGPT 账号注册与登录问题排查。
- Plus、Pro、Team 等套餐升级咨询与协助。
- OpenAI API 开通、Key 获取和基础配置。
- GPTs、自定义助手、插件和工作流使用指导。
- ChatGPT 网页端、客户端、移动端使用问题排查。

### Gemini

Gemini 是 Google 的 AI 模型和产品体系，和 Google 搜索、Docs、Gmail、Drive、Android 等生态结合紧密。它适合资料检索、长上下文阅读、多模态理解、办公协作和 Google 生态用户的 AI 辅助。

酷里可以协助：

- Google 账号注册、登录、验证和安全设置。
- Gemini 使用、订阅和套餐咨询。
- Google One、Google AI Pro 等相关服务配置。
- Gemini API、Google AI Studio 和开发环境配置。
- Google 生态服务与 AI 工具联动咨询。

### Claude

Claude 是 Anthropic 的 AI 助手，擅长长文阅读、复杂推理、代码协作、文档理解和稳健写作。Claude Code 则面向开发者，可以在本地项目里协助读代码、改代码、跑测试和处理工程任务。

酷里可以协助：

- Claude 账号、订阅和使用问题处理。
- Claude Pro、Max、Team 等套餐咨询。
- Claude Code 安装、授权、登录和项目配置。
- Claude API Key、环境变量和调用示例配置。
- Claude 在写作、论文、代码、数据整理中的使用流程设计。

### Grok

Grok 是 xAI 的 AI 产品，适合结合实时信息、社交平台内容和通用问答场景使用。它在信息追踪、热点理解、内容生成和部分多模态能力上有自己的特点。

酷里可以协助：

- Grok 账号、订阅和使用入口咨询。
- Grok API 或相关开发能力配置。
- Grok 与其他 AI 工具的组合使用建议。
- 常见登录、支付、额度、访问问题排查。

### Telegram

Telegram 是海外常用即时通讯工具，很多 AI 社群、机器人、自动化通知、项目协作和服务支持都会用到它。对于需要接入 Bot、频道通知、群组管理或跨境协作的用户，Telegram 经常是基础工具。

酷里可以协助：

- Telegram 账号注册、登录和安全设置。
- Telegram Bot 创建、Token 配置和基础接入。
- 频道、群组、通知机器人和自动化提醒配置。
- Telegram 与 AI 工具、网站、小程序、服务器的联动。

### Cursor

Cursor 是面向程序员和产品开发者的 AI 代码编辑器，可以在项目里读代码、写代码、改 bug、生成组件和解释工程结构。它适合从 demo 到真实项目的快速开发。

酷里可以协助：

- Cursor 安装、登录、订阅和模型配置。
- 项目导入、代码索引、规则文件和工作区配置。
- 接入 OpenAI、Anthropic、Gemini 或中转模型。
- 帮用户设计适合自己项目的 AI 编程工作流。

### Claude Code

Claude Code 是命令行里的 AI 编程助手，适合在真实代码仓库中协作：读文件、理解架构、改代码、跑测试、提交变更。它对工程化开发、复杂项目维护和自动化处理很有价值。

酷里可以协助：

- Claude Code 安装、登录、授权和升级。
- 本地项目配置、环境变量配置和权限设置。
- 和 Git、GitHub、测试命令、构建命令配合使用。
- 设计适合个人或团队的 Claude Code 工作方式。

### Codex

Codex 是面向代码任务的 AI 编程环境，可以协助完成前端、后端、脚本、文档、测试、重构、调试和本地项目自动化。它适合把自然语言需求转成真实代码变更。

酷里可以协助：

- Codex 安装、登录、模型和项目配置。
- 本地仓库接入、开发环境检查和命令配置。
- Codex 与 GitHub、Playwright、文档工具链等能力配合。
- 为项目编写 AGENTS.md、README、启动脚本和开发规范。

### Antigravity

Antigravity 是面向 AI 开发与自动化的新一代工具形态，重点在于让 AI 更主动地理解项目、规划任务、执行开发和验证结果。它适合希望把 AI 当成开发协作者或自动化代理的用户。

酷里可以协助：

- Antigravity 安装、账号、模型和工作区配置。
- 项目导入、Agent 工作流设置和开发流程调试。
- 与现有 IDE、代码仓库和部署流程结合。
- 帮用户判断 Antigravity、Cursor、Claude Code、Codex 之间怎么搭配。

### Grok Build

Grok Build 可以理解为围绕 Grok 或 xAI 生态进行应用构建、模型调用和 AI 产品开发的一类能力入口。适合想把 Grok 接进自己的网页、工具、机器人或自动化流程的用户。

酷里可以协助：

- Grok Build 相关账号、API、模型和开发环境配置。
- 把 Grok 能力接入网站、小程序、Bot 或内部工具。
- 处理调用报错、鉴权、额度、模型选择和接口参数问题。
- 设计从 demo 到可用产品的接入方案。

### API Key、中转站与模型服务

API Key 是把 AI 模型接入自己工具、网站、脚本或应用的钥匙。中转站则常用于统一管理不同模型、不同供应商、额度、密钥和调用地址，让团队或项目更容易切换模型和控制成本。

酷里可以协助：

- OpenAI、Claude、Gemini、Grok 等 API Key 获取和配置。
- 中转站选择、部署、接入和模型路由配置。
- 环境变量、代理、鉴权、额度、并发和错误码排查。
- 把 API 接入到网页、Bot、小程序、自动化脚本或业务系统。
