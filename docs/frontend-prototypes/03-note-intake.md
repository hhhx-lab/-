# 写张小纸条页原型图实现说明

对应原型：`前端图片/写张小纸条.jpg`  
目标路由：`/note`  
当前代码：`apps/web/app/pages/note.vue`

## 页面定位

小纸条页是酷里的核心下单入口。它不是后台表单，而是“用户用口语把需求丢给酷里”的引导页。设计目标是让用户不用懂需求分类，也能快速提交足够信息。

## 页面结构

整体为左右两栏：

- 左侧：主表单，大约占 70% 宽度。
- 右侧：示例聊天 + 小贴士，大约占 30% 宽度。

顶部导航与其他页面一致。页面标题区在导航下方，左对齐：

```text
写张小纸条给酷里
```

“酷里”高亮黄绿，标题右侧有蓝色纸飞机涂鸦图标。副标题：

```text
不用写得太专业，直接说你想干嘛、哪里卡住了、希望什么时候搞定就行。
```

## 左侧主表单

表单是一个大深色面板，内部按 7 个编号区块排列。编号为黄绿色圆点，数字醒目。

### 1. 你想搞什么？

标题后有辅助说明：

```text
越详细越好，我们更容易理解
```

大文本框高度约 120-140px，placeholder 示例为多行：

```text
例如：
我想开通 GPT Pro，但是不会弄
我想注册 Google 账号
我有个 PDF 想翻译并保留格式
我想做一个课程项目网页 demo
```

右下角显示字数 `0 / 800`。当前实现为 `1000` 字，可按原型改为 `800` 或保留但视觉显示更轻。

### 2. 大概属于哪一类？

使用一组胶囊选项：

- GPT / AI 工具
- Google / 账号相关
- Claude / AI 工具
- 文档处理
- 小工具开发
- 部署配置
- 不知道怎么分

选中态：黄绿色边框、深色背景略亮；未选中为灰色描边。

### 3. 什么时候需要？

胶囊选项：

- 今天
- 1-2 天
- 3-5 天
- 不急
- 先聊聊

### 4. 能不能远程帮你看？

标题右侧有小信息图标。选项：

- 可以远程，方便你们直接帮我看
- 暂时不方便，先文字或截图沟通
- 看情况，需要的时候再说

下方小提示：

```text
有些安装、配置、报错类问题，远程看会快很多。
```

### 5. 预算大概多少？

选项：

- 50 元以内
- 50-100
- 100-300
- 300-1000
- 1000+
- 先报价看看

### 6. 有截图 / 文件 / 报错的话，也可以传一下

上传区域为虚线框：

- 中央云上传图标。
- 文案：“点击或拖拽文件到这里上传”。
- 小字：“支持图片、PDF、文档、压缩包等，单个文件 <= 50MB”。

当前实现已经支持 `input type=file` 和上传逻辑，但视觉要改成拖拽面板。第一阶段可以只做点击上传，拖拽后续补。

### 7. 怎么联系你？

左侧是联系方式类型按钮：

- 微信
- QQ
- 邮箱

右侧为对应输入框。原型默认选中微信，输入框 placeholder 为“请输入你的微信号”。下方提示：

```text
仅用于沟通，不会对外公开。
```

当前实现要求邮箱和其他联系方式都必填；原型更接近“选择一种主要联系方式 + 输入内容”。后续可改 API 入参为统一 `contactType/contactValue`，或前端仍拼接成现有 `contact` 字段。

## 表单底部

提交前有横向提醒条：

```text
小活可以先做完再结；大一点的活可能要先付点定金。默认不包长期售后，部署 / 维护 / 修改另算。
```

主提交按钮：

```text
把小纸条丢给酷里
```

按钮为全宽荧光黄绿，左侧纸飞机图标，黑字，字号较大。

## 右侧辅助栏

右侧是一张深色面板，顶部有蓝色便利贴：

```text
不知道怎么写？
直接说人话就行！
```

面板标题：

```text
不知怎么描述也没关系
```

副文案：

```text
你可以像下面这样说 -
```

示例聊天卡片 4 条：

1. 我想开通 GPT Pro，但是不会弄 🙂
2. 我想注册一个 Google 账号 👍
3. 我的 PDF 需要翻译，还要保持排版 📚
4. 想做一个课程项目网页 demo，有设计稿 🚀

每条左侧有 Kuli 圆形头像，右侧为深色消息气泡。

下方分割线后是“小贴士”列表：

- 越具体，越容易搞定：把你的目标、遇到的问题、期望效果说清楚，节省来回沟通时间。
- 带上截图 / 报错信息：有图有真相，我们能更快定位问题。
- 时间越准越好：告诉我们的时间要求，便于安排优先级。

右下角有黄绿色便利贴：

```text
收到你的纸条后，
酷里会尽快回复你~
- Kuli :)
```

## 当前实现改造映射

- `apps/web/app/pages/note.vue`
  - 当前已经有服务选择、需求、材料、AI 整理、时间预算、联系方式、预览。需要按原型重排为 7 个编号区块。
  - 当前左侧 `note-assist` 和右侧 `note-preview` 的信息结构与原型不一致。原型要求右侧展示示例和小贴士，提交预览可以变成折叠区或提交前摘要。
  - 当前“小酷整理”作为独立第 3 步。原型没有显式 AI 整理区，可保留为文本框旁的辅助按钮，但不要打断 7 步表单。
  - 当前联系方式要求邮箱 + 其他联系方式必填。原型建议改成联系方式类型切换。
  - 当前上传控件是原生 input，需要改成虚线拖拽面板。

## 交互细节

- 点击热门需求页带来的 `topic` 时，需求文本框可预填一句“我想咨询：{topic}”。
- 服务分类选中后，右侧示例可以切换为该分类对应示例。
- 提交按钮禁用时仍要显示，但透明度降低； hover 不应触发强光。
- 文件选择后在上传框下方显示文件名、大小、删除按钮。
- 未登录用户提交时如果后端需要登录，应给出明确登录弹窗或跳转，不要只报错。

## 响应式要求

- 1100px 以下：左右两栏改为单列，右侧辅助栏放在表单下方。
- 760px 以下：标题缩小；选项胶囊允许换行；提交按钮固定在内容底部，不遮挡输入框。
- 480px 以下：右侧示例聊天保留 2-3 条即可，便利贴装饰隐藏。

## 组件级实现规格

写小纸条页是最适合直接按组件实现的页面。建议拆成 `NotePageHero`、`NoteIntakeLayout`、`NoteFormPanel`、`NoteStepBlock`、`SegmentedChoiceGroup`、`DropzoneUpload`、`ContactMethodInput`、`NoteSubmitNotice`、`NoteExampleAside`、`ExampleMessageList`、`TipChecklist`。

### 1. `NotePageHero`

位置：导航下方、主表单上方。

结构：

- H1：“写张小纸条给酷里”，其中“酷里”高亮。
- 纸飞机涂鸦图标，位于标题右侧或标题末尾。
- 副标题：“不用写得太专业，直接说你想干嘛、哪里卡住了、希望什么时候搞定就行。”

尺寸：

- 桌面端 H1 54-64px，高度约 120px。
- 与表单区域间距 18-24px。

实现要点：

- 这是任务页标题，不要像首页 hero 那样加入大视觉图。
- 纸飞机可以使用 icon library；如果没有，先用 CSS/文本图标占位，但要保留尺寸。

### 2. `NoteIntakeLayout`

位置：页面主内容。两栏布局。

网格：

```css
grid-template-columns: minmax(0, 1fr) 360px;
gap: 18px;
align-items: stretch;
```

左栏为 `NoteFormPanel`，右栏为 `NoteExampleAside`。桌面端两栏顶部对齐，高度接近；右栏可 sticky，但不能超过视口导致底部不可达。

### 3. `NoteFormPanel`

外层大面板，承载 7 个步骤和提交按钮。

样式：

- 背景 `rgba(10, 11, 11, 0.92)`。
- 边框 `rgba(255,255,255,0.12)`。
- 圆角 16px。
- 内边距 18-20px。
- 步骤之间间距 18px。

实现：

```vue
<form class="note-form-panel">
  <NoteStepBlock number="1" title="你想搞什么？" hint="越详细越好，我们更容易理解">
    ...
  </NoteStepBlock>
  ...
</form>
```

### 4. `NoteStepBlock`

所有步骤使用同一个组件骨架。

结构：

- `stepHeader`
  - `stepNumber`：黄绿色圆点，24-28px。
  - `title`：18-20px。
  - `hint`：可选，小号灰字，跟在标题后。
- `stepContent`

样式：

- 步骤本身不做独立卡片边框，依赖大面板；只有上传框、输入框和选项需要边框。
- 标题行高度约 30px。
- 每个步骤内容上方 10-12px。

### 5. `NeedTextareaStep`

对应第 1 步“你想搞什么？”。

输入框规格：

- 高度 120-140px。
- 圆角 10-12px。
- 背景 `rgba(255,255,255,0.045)`。
- 边框 `rgba(255,255,255,0.12)`。
- 内边距 16px。
- 字号 15px，行高 1.7。

placeholder 必须多行，直接写原型中的示例。字数统计固定在右下：

```text
0 / 800
```

状态：

- focus：黄绿边框。
- over limit：字数统计变红，提交按钮禁用。
- empty：不显示错误，只有提交时提示。

### 6. `SegmentedChoiceGroup`

对应第 2、3、4、5 步的胶囊选项。

字段：

```ts
type ChoiceOption = {
  label: string;
  value: string;
  icon?: string;
  disabled?: boolean;
};
```

样式：

- 每个选项高度 38-42px。
- 圆角 10-12px。
- 横向间距 10px，纵向间距 10px。
- 未选中：深色背景 + 灰边框。
- 选中：黄绿边框 + 略亮背景；如果是联系方式选中，可用黄绿填充。

交互：

- 使用真实 radio/checkbox 语义，但视觉隐藏原生控件。
- 键盘可 Tab 聚焦，Space/Enter 选择。
- 多行换行时保持左对齐，不要居中堆叠。

### 7. `RemoteSupportStep`

第 4 步“能不能远程帮你看？”。

特殊要求：

- 标题右侧有小 `info` 图标，hover 或 focus 时显示 tooltip：“安装、配置、报错类问题远程会更快；是否远程由你确认。”
- 选项比普通胶囊更长，允许 3 个并排或换行。
- 下方提示行带小太阳/提示图标，颜色更弱。

### 8. `DropzoneUpload`

第 6 步上传框。

结构：

- 外层虚线框，高 74-90px。
- 中间云上传图标。
- 主文案：“点击或拖拽文件到这里上传”。
- 小文案：“支持图片、PDF、文档、压缩包等，单个文件 <= 50MB”。

状态：

- default：虚线边框灰色。
- hover/dragover：边框黄绿，背景略亮。
- selected：下方显示 `SelectedFileList`。
- error：边框红色，显示错误说明。

文件列表：

- 每行：文件图标、文件名、大小、删除按钮。
- 文件名必须可截断，保留扩展名。

实现约束：

- 第一阶段可只支持点击选择文件，文档仍保留拖拽目标样式。
- 当前 API 上传逻辑可以复用 `uploadAttachments`。

### 9. `ContactMethodInput`

第 7 步联系方式。

结构：

- 左侧或上方 `SegmentedChoiceGroup`：微信、QQ、邮箱。
- 右侧输入框根据选中方式切换 placeholder：
  - 微信：请输入你的微信号
  - QQ：请输入你的 QQ 号
  - 邮箱：请输入你的邮箱
- 下方说明：“仅用于沟通，不会对外公开。”

数据建议：

```ts
type ContactMethod = "wechat" | "qq" | "email";
const contactPayload = computed(() => `${contactMethod.value}: ${contactValue.value}`);
```

兼容当前后端：

- 如果后端仍只接收 `contact` 字段，前端提交 `contactPayload`。
- 如果已有登录邮箱，可默认选择邮箱并预填，但用户可以切换。

### 10. `NoteSubmitNotice`

提交按钮上方的黄绿边框提醒条。

结构：

- 铃铛图标。
- 文案为原型中的交易规则。

样式：

- 高度 48-54px。
- 圆角 10-12px。
- 边框黄绿透明。
- 字号 14-15px。

### 11. `NoteSubmitButton`

全宽主按钮。

规格：

- 高度 56-60px。
- 背景黄绿。
- 黑字，字重 850。
- 左侧纸飞机图标，22px。
- 文案：“把小纸条丢给酷里”。

状态：

- disabled：透明度 0.45，鼠标 `not-allowed`。
- loading：文案“正在丢给酷里...”，图标可变为 spinner。
- success：不在按钮内显示长结果，使用提交成功卡片或跳转订单页。

### 12. `NoteExampleAside`

右侧辅助栏大面板。

结构：

- 顶部蓝色便利贴。
- 标题和副标题。
- `ExampleMessageList`。
- 分割线。
- `TipChecklist`。
- 底部黄绿色便利贴。

面板样式：

- 背景和表单面板一致。
- 圆角 16px。
- 内边距 22-24px。
- 高度与左侧表单接近；内容不足时底部便利贴靠下。

### 13. `ExampleMessageList`

示例聊天列表。

每条结构：

- 左侧圆形 Kuli 头像，34px。
- 右侧气泡，深色背景，圆角 12px。
- 文案最多两行，右侧可放 emoji。

数据：

```ts
const exampleMessages = [
  { text: "我想开通 GPT Pro，但是不会弄", emoji: "🙂" },
  { text: "我想注册一个 Google 账号", emoji: "👍" },
  { text: "我的 PDF 需要翻译，还要保持排版", emoji: "📚" },
  { text: "想做一个课程项目网页 demo，有设计稿", emoji: "🚀" }
];
```

交互：

- 点击示例气泡可把文本填入第 1 步文本框。
- hover 气泡边框变黄绿。

### 14. `TipChecklist`

小贴士列表。

每条结构：

- 左侧黄绿 check 图标。
- 标题。
- 一行说明。

内容固定 3 条：

- 越具体，越容易搞定。
- 带上截图 / 报错信息。
- 时间越准越好。

移动端：

- 右侧栏移动到表单下方。
- 示例消息可变成 2 列小卡或纵向列表。
