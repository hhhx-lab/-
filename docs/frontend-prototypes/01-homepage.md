# 首页原型图实现说明

对应原型：`前端图片/主页.jpg`  
目标路由：`/`  
当前代码：`apps/web/app/pages/index.vue`、`apps/web/app/layouts/default.vue`、`apps/web/app/assets/css/main.css`

## 页面定位

首页要从当前“普通 hero + 卡片网格”升级成酷里的品牌入口。用户第一眼应理解三件事：

1. 酷里是一个可以先聊需求的小窗口。
2. 常见问题包括 AI 工具、账号订阅、API、文档、小工具、部署配置。
3. 不用先写完整方案，直接写小纸条即可进入判断流程。

## 首屏结构

### 顶部导航

桌面端顶部是黑色固定横栏：

- 左侧：白色 Kuli 图形 logo + “酷里 Kuli” + 小胶囊“酷里小窗口”。
- 中间：导航项依次为“热门需求 / 文档处理 / AI 工具 / 小工具开发 / 部署配置 / 我的订单”。
- 右侧：荧光黄绿主按钮“写张小纸条”，左侧带铅笔图标。

导航高度约 64px，底部有极细分割线。导航背景需要比页面背景略实，保证滚动时仍清晰。

### Hero 左侧

左侧主标题为：

```text
搞不动？
先丢给酷里看看。
```

其中“酷里”使用荧光黄绿强调。标题为两行，字号大、字重厚，靠左，行高紧凑。标题下方是说明文案：

```text
我们是一个 AI 创客小队。文档、AI 工具、账号/订阅咨询、API 配置、
小程序、网页、数据库、部署这些，都可以先聊聊。
```

说明文案保持灰白色，最多两行，宽度控制在 560px 左右。

CTA 两个：

- 主按钮“写张小纸条”：荧光黄绿填充，带铅笔图标。
- 次按钮“看看大家都在问什么”：黑底描边，带聊天气泡图标。

### Hero 右侧

右侧是“需求聊天窗口 + 便利贴”的组合。

聊天窗口：

- 深黑半透明面板，圆角约 18px。
- 左上角有红黄绿窗口控制点。
- 首行小提示带 `$` 符号：“你想搞定什么？”。
- 消息气泡示例：
  - 左侧白色气泡：“注册国外谷歌账号”
  - 右侧深色气泡：“购买谷歌 Pro”
  - 左侧深色气泡：“购买 gptPro”
  - 底部打字状态气泡：“...”

便利贴：

- 蓝色便利贴放右上，微旋转，文案：“先聊聊需求 / 能搞定再开工 / - 酷里小队”。
- 黄绿色便利贴放右下，文案：“小需求当天搞定 / 大需求按里程碑来 / - Kuli :)”。
- 可增加胶带、星形线稿、蓝色涂鸦箭头，但装饰不能覆盖聊天窗口。

## 内容区 1：最近大家问得最多

标题左侧有火焰图标，标题为“最近大家问得最多”。下方是 6 张横向卡片，一行展示。

卡片列表：

1. GPT / Pro / API
   - 图标：OpenAI 风格绿色图标
   - 描述：GPT Pro 订阅、API 开通与使用问题
2. Google / Gemini / 海外工具
   - 图标：Google G
   - 描述：注册谷歌账号、Gemini、Google One 等订阅
3. Claude / Claude Code
   - 图标：AI 字样
   - 描述：Claude 订阅、Claude Code 授权与使用
4. API Key / 中转站 / token
   - 图标：钥匙
   - 描述：OpenAI / Claude / 各类 API Key 与中转服务
5. 工具安装 / 网络环境
   - 图标：地球
   - 描述：软件安装、环境配置、网络与代理问题
6. 不知道选啥，直接问
   - 图标：聊天
   - 描述：不确定从哪里开始？先说说你的情况

每张卡片底部都有黄绿色小链接“去看看 ->”。卡片 hover 时边框变亮，图标轻微上浮。

## 内容区 2：酷里大概能搞

该区标题左侧是工具/扳手图标，标题为“酷里大概能搞”。采用 4 张宽卡片，两列或四列布局。

卡片：

- 文档急救：论文/报告/方案/简历等修改、润色、排版，AI 翻译写作与内容整理。
- AI 工具配置：各类 AI 工具订阅、账号注册、API 配置与使用问题。
- 小工具开发：脚本、自动化、小程序、网页等小需求的工具便利开发。
- 部署上线：网站/小程序/项目部署、数据库、域名、服务器等环境配置。

宽卡片更像服务入口，不要做成等权营销卡片。每张卡片内部含图标、标题、两行说明和“去看看”按钮。

## 内容区 3：我们怎么做

流程为 5 步横向卡片，用虚线箭头连接：

1. 你先说需求：写张小纸条，告诉我们你想要做什么。
2. 我们判断能不能做：评估可行性、给出思路、方案和大致报价。
3. 先跑一个初版：先交付一个可用版本，你先看看效果。
4. 满意后继续：有问题继续调整优化，直到你满意。
5. 验收后付款：确认 ok 后再付款，简单透明。

移动端改为纵向流程，不允许横向溢出。

## 底部提醒和页脚

流程下方有一条横向提示条，左侧铃铛图标，文案：

```text
小活可以先做完再结；大一点的活可能要先付点定金。默认不包长期售后，部署 / 维护 / 修改另算。
```

页脚：

- 左侧 logo 和“酷里 Kuli”
- 小字：“不保证什么都能做，但能试的我们都会先试试。”
- 右侧重复主 CTA“写张小纸条”和三个联系图标。

## 响应式要求

- 1180px 以下：hero 右侧聊天窗口可缩小，便利贴保留但减少旋转。
- 900px 以下：hero 改为单列，聊天窗口放标题下方；热门需求卡片改为 2 列。
- 560px 以下：导航两行或抽屉；标题 34-38px；所有卡片单列；流程竖排。

## 组件级实现规格

本节按原型从上到下拆解中间区域的每个可实现组件。实现时建议把首页拆成 `HomeHero`、`NeedShortcutStrip`、`CapabilityGrid`、`HomeProcessRail`、`HomeNoticeBar`、`HomeFooterCta` 等局部组件，避免继续堆在一个大模板里。

### 1. `HomeHero`

位置：导航下方首屏，左右两栏。左栏占 46%-50%，右栏占 50%-54%。桌面端容器高度建议 320-380px，底部应露出“最近大家问得最多”标题。

结构：

- `heroCopy`：标题、副标题、两个 CTA。
- `heroVisual`：聊天窗口、蓝色便利贴、黄绿色便利贴、星形线稿、蓝色涂鸦箭头。

视觉规格：

- `hero` 容器不要使用独立卡片背景，直接落在黑色画布上。
- 左侧标题宽度 620px 以内；右侧视觉区允许轻微重叠，但不能溢出页面外。
- 标题字重 900，行高 1.08，`酷里` 使用主强调色。
- CTA 行间距 20px，两个按钮高度 52px，主按钮宽约 202px，次按钮宽约 240px。

数据字段：

```ts
type HomeHeroContent = {
  titleLines: string[];
  highlight: string;
  subtitle: string;
  primaryCta: { label: string; to: string; icon: "pencil" };
  secondaryCta: { label: string; to: string; icon: "message" };
};
```

交互：

- 主 CTA 点击跳转 `/note`。
- 次 CTA 点击滚动到热门需求区，或跳转 `/services`。
- hover 主按钮：背景提高亮度，图标向右上微移 1-2px。
- hover 次按钮：边框从灰色变黄绿。

验收：

- 1440px 宽度下标题、按钮、聊天窗口三者必须同屏可见。
- 375px 宽度下标题不超过 3 行，右侧视觉区位于 CTA 下方。

### 2. `HeroChatWindow`

位置：Hero 右侧主体视觉中心。尺寸约 370x255px，靠右但留出便利贴空间。

结构：

- `windowChrome`：红黄绿 3 个圆点。
- `promptLine`：绿色 `$` 符号 + “你想搞定什么？”。
- `messageBubbles`：4 个气泡 + 1 个打字状态。

样式：

- 面板背景 `rgba(12, 13, 13, 0.92)`。
- 边框 `rgba(255,255,255,0.14)`。
- 圆角 18px。
- 内边距 24px。
- 右侧气泡颜色比面板浅，左侧白色气泡用浅灰底黑字。
- 打字状态气泡宽约 68px，高约 34px，内部 3 个点。

内容示例：

```ts
const heroMessages = [
  { side: "left", tone: "light", text: "注册国外谷歌账号" },
  { side: "right", tone: "dark", text: "购买谷歌 Pro" },
  { side: "left", tone: "dark", text: "购买 gptPro" },
  { side: "left", tone: "typing", text: "..." }
];
```

交互：

- 页面首次加载时可做 120ms 间隔的轻微浮入，但不能循环跳动。
- 不需要真实聊天功能；真实小酷仍由右下角小酷组件承担。

### 3. `StickyNoteCluster`

位置：Hero 右侧，蓝色便利贴压在聊天窗口右上，黄绿色便利贴压在右下。

蓝色便利贴：

- 宽约 150px，高约 118px。
- 旋转约 `-7deg`。
- 文案 3 行，字体 17-18px，字重 700。
- 顶部有半透明胶带，宽 48px，高 18px。

黄绿色便利贴：

- 宽约 170px，高约 120px。
- 旋转约 `7deg`。
- 文案包含 `- Kuli :)`。
- 右下有笑脸符号或图标。

注意：

- 便利贴是装饰和品牌语气，不要把关键业务信息只放在便利贴里。
- 移动端隐藏蓝色涂鸦和星形，只保留一张便利贴或全部隐藏。

### 4. `NeedShortcutStrip`

位置：Hero 下方第一段。标题为“最近大家问得最多”，左侧火焰图标。

布局：

- 桌面端 6 列，每张卡宽约 210px，高约 160px。
- 1180px 以下改为 3 列 2 行。
- 640px 以下改为单列或横向滑动。

卡片结构：

- 顶部图标容器 48x48px。
- 标题 16-18px。
- 描述 2 行，最多 44px 高。
- 底部链接“去看看 ->”。

字段：

```ts
type NeedShortcut = {
  title: string;
  description: string;
  icon: "openai" | "google" | "claude" | "key" | "globe" | "chat";
  to: string;
  accent: "green" | "google" | "orange" | "blue" | "purple" | "lime";
};
```

交互：

- 卡片整体可点击。
- hover：边框变亮，背景从 `rgba(255,255,255,0.035)` 到 `rgba(255,255,255,0.06)`。
- 键盘 focus：显示黄绿色外轮廓。

### 5. `CapabilityGrid`

位置：“酷里大概能搞”区。用于展示 4 个大能力入口。

布局：

- 桌面端 4 列，卡片宽约 310px，高约 126px。
- 卡片比热门需求卡更宽，信息更横向。

卡片内容：

- 图标左侧或左上，44-48px。
- 标题：文档急救、AI 工具配置、小工具开发、部署上线。
- 描述：1-2 行。
- 小型描边按钮“去看看 ->”。

实现要求：

- 这组卡片应使用 `NuxtLink`，分别指向对应服务详情或 `/note?service=`。
- 不要使用纯数字作为图标，必须是语义图标。

### 6. `HomeProcessRail`

位置：“我们怎么做”区。5 个步骤横向排布，中间虚线箭头连接。

步骤卡片结构：

- 左侧编号圆点，32px，黄绿/蓝/紫等状态色。
- 图标 36-42px。
- 标题 15-16px。
- 描述 1-2 行。

字段：

```ts
type ProcessStep = {
  number: 1 | 2 | 3 | 4 | 5;
  title: string;
  description: string;
  icon: "chat" | "clipboard" | "terminal" | "refresh" | "check";
  tone: "lime" | "blue" | "purple" | "neutral" | "green";
};
```

连接线：

- 桌面端卡片之间使用 `::after` 或独立 `ProcessConnector`。
- 连接线为 `1px dashed rgba(255,255,255,0.45)`。
- 移动端改为竖向左侧线，不能横向滚动。

### 7. `HomeNoticeBar`

位置：流程下方。横向全宽提示条。

结构：

- 左侧铃铛图标。
- 中间完整提示文案。
- 可选右侧“查看规则”短链接。

样式：

- 高度 52-58px。
- 黄绿色细边框。
- 背景极深黑。
- 文案字号 15px，字重 500。

### 8. `HomeFooterCta`

位置：页脚区域上方或页脚内。原型页脚左侧品牌，右侧 CTA 和联系图标。

结构：

- 左侧品牌 logo + “酷里 Kuli” + 一行说明。
- 右侧主按钮“写张小纸条”。
- 右侧图标按钮：微信、邮箱、GitHub/代码仓库。

实现细节：

- 联系图标按钮是 42x42px 正方形，圆角 10-12px。
- 图标按钮 hover 时边框变亮。
- 移动端改为品牌在上，按钮和图标在下。
